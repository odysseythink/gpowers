# gpowers platforms/ + Kimi Adapter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For each of the 7 supported platforms (Claude Code, Codex, Gemini, Cursor, OpenCode, Copilot CLI, Kimi), generate the platform-specific registration assets — `plugin.json`, slash command files in `commands/`, `skills.json` mapping, and `hooks.json` where supported. Implement a `gen-kimi-adapters` subcommand that builds `gpowers-<name>/SKILL.md` wrappers under `~/.kimi/skills/` because Kimi cannot resolve symlinks to a single source the way the other six platforms do.

**Architecture:** Single source of truth lives in `~/.gpowers/{core,roles,tools,business}/skills/`. For each platform we own a generator that emits the platform's native registration manifest into `~/.gpowers/platforms/<platform>/`. The install script (Plan #1) creates a symlink from the platform's expected plugin directory (`~/.claude/plugins/gpowers/`, `~/.config/gemini/extensions/gpowers/`, etc.) to `~/.gpowers/platforms/<platform>/` — so platform A discovers gpowers, reads its own `plugin.json`, and follows the relative paths back into `~/.gpowers/{core,roles,tools,business}/skills/`. Kimi is the exception: it needs each skill flat-namespaced as `gpowers-<name>/`, with `using-gpowers` content inlined into every adapted skill's preamble (because Kimi has no SessionStart hook). `gen-kimi-adapters` reads the four modules and produces these wrappers.

**Tech Stack:** Bash 4+, jq (manifest generation), Markdown, Plan #2's `using-gpowers` content (preamble), bats-core, fixture skills from Plans #2, #4–7.

**Depends on:** Plans #1 (install layout + manifest), #2 (using-gpowers content + session-start hook), #4 (tools/), #5 (tools-browser), #6 (roles/), #7 (business/). The Kimi generator reads from all four modules.

## Task 1: Define the platform → registration shape table

**Files:**
- Create: `platforms/_platform-shapes.json`

A single declarative file the generator reads. Each platform entry declares:
- `manifest_filename` — `plugin.json` / `extension.json`
- `manifest_schema` — minimal JSON object the generator produces
- `command_dir` — relative path under `platforms/<platform>/` for command files
- `command_filename_pattern` — `<slash>.md` or `<slash>.json`
- `supports_hooks` — true/false
- `injection_target` — for Cursor and Gemini, the file the install script appends to
- `namespace_mode` — `plugin-scoped` | `extension` | `flat-prefix` | `cursor-rules`

This data drives Tasks 3–4. Adding an 8th platform later means appending one entry here, not editing generator logic.

- [ ] **Step 2: Write the helper**

```bash
cat > bin/_gpowers-list-slashes.sh <<'EOF'
#!/usr/bin/env bash
# Emits TSV: slash<TAB>module<TAB>skill_dir<TAB>requires_driver
set -euo pipefail
: "${GPOWERS_HOME:?GPOWERS_HOME required}"

for module in core roles tools business; do
  dir="$GPOWERS_HOME/$module/skills"
  [ -d "$dir" ] || continue
  for skill in "$dir"/*/; do
    [ -d "$skill" ] || continue
    file="$skill/SKILL.md"
    [ -f "$file" ] || continue
    slash=$(awk -F': ' '/^slash:/ {print $2; exit}' "$file")
    [ -n "$slash" ] || continue
    driver=$(awk -F': ' '/^requires-driver:/ {print $2; exit}' "$file")
    [ -n "$driver" ] || driver="none"
    skill_dir=$(basename "$skill")
    printf '%s\t%s\t%s\t%s\n' "$slash" "$module" "$skill_dir" "$driver"
  done
done | sort
EOF
chmod +x bin/_gpowers-list-slashes.sh
```

- [ ] **Step 2: Write the generator**

```bash
cat > bin/_gpowers-gen-platform.sh <<'EOF'
#!/usr/bin/env bash
# Usage: _gpowers-gen-platform.sh <platform>
# Reads $GPOWERS_HOME/platforms/_platform-shapes.json + the slash catalog,
# writes $GPOWERS_HOME/platforms/<platform>/{<manifest>,skills.json,commands/...,hooks.json}.
set -euo pipefail

: "${GPOWERS_HOME:?GPOWERS_HOME required}"
PLATFORM="${1:?platform name required}"
SHAPES="$GPOWERS_HOME/platforms/_platform-shapes.json"
[ -f "$SHAPES" ] || { echo "shapes file missing: $SHAPES" >&2; exit 1; }

# Pull this platform's shape
shape() { jq -r --arg p "$PLATFORM" ".platforms.\$p.$1" < "$SHAPES"; }
MANIFEST=$(shape manifest_filename)
COMMAND_DIR=$(shape command_dir)
SUPPORTS_HOOKS=$(shape supports_hooks)
NS_MODE=$(shape namespace_mode)
[ "$MANIFEST" != "null" ] || { echo "unknown platform: $PLATFORM" >&2; exit 1; }

OUT="$GPOWERS_HOME/platforms/$PLATFORM"
mkdir -p "$OUT/$COMMAND_DIR"

# 1) plugin/extension manifest
jq -n --arg name gpowers \
      --arg version "1.0.0" \
      --arg ns "$NS_MODE" \
      '{
        "$schema": "https://gpowers.dev/schemas/plugin.json",
        name: $name,
        version: $version,
        namespace_mode: $ns,
        description: "gpowers — unified methodology + roles + tools + business automation",
        modules: ["core","roles","tools","business"]
      }' > "$OUT/$MANIFEST"

# 2) skills.json: complete index across all four modules
SKILLS_JSON='{ "skills": [] }'
for module in core roles tools business; do
  dir="$GPOWERS_HOME/$module/skills"
  [ -d "$dir" ] || continue
  for s in "$dir"/*/; do
    [ -d "$s" ] || continue
    file="$s/SKILL.md"
    [ -f "$file" ] || continue
    name=$(basename "$s")
    desc=$(awk -F': ' '/^description:/ {sub(/^description: /, ""); print; exit}' "$file")
    SKILLS_JSON=$(echo "$SKILLS_JSON" | jq \
      --arg n "$name" \
      --arg m "$module" \
      --arg d "$desc" \
      --arg p "$module/skills/$name/SKILL.md" \
      '.skills += [{name: $n, module: $m, description: $d, path: $p}]')
  done
done
echo "$SKILLS_JSON" > "$OUT/skills.json"

# 3) Command files (one .md per slash)
"$GPOWERS_HOME/bin/_gpowers-list-slashes.sh" | while IFS=$'\t' read -r slash module skill_dir driver; do
  cmd_name="${slash#/}"
  cmd_file="$OUT/$COMMAND_DIR/$cmd_name.md"
  cat > "$cmd_file" <<MD
---
slash: $slash
module: $module
skill: $skill_dir
requires_driver: $driver
---

<!-- SOURCE: \$GPOWERS_HOME/$module/skills/$skill_dir/SKILL.md -->

This command invokes the gpowers skill **$skill_dir** ($module).

Refer to the source SKILL.md (above) for the full workflow. The platform's skill mechanism will load it on demand.
MD
done

# 4) hooks.json (where supported)
if [ "$SUPPORTS_HOOKS" = "true" ]; then
  cp "$GPOWERS_HOME/core/hooks/hooks.json" "$OUT/hooks.json"
fi

echo "platforms/$PLATFORM/ generated."
EOF
chmod +x bin/_gpowers-gen-platform.sh
```

## Task 5: Write the Kimi adapter generator

**Files:**
- Create: `bin/_gpowers-gen-kimi.sh`

Kimi can't follow symlinks back to `~/.gpowers/`, and has no SessionStart hook. So we generate flat `gpowers-<name>/SKILL.md` directories under `platforms/kimi/adapters/`. Each adapter:
1. Frontmatter: `name: gpowers-<original>`, `gpowers-source: <module>/skills/<original>/SKILL.md`
2. Preamble that inlines the using-gpowers content (4-module model)
3. Body: `<!-- SOURCE: ${GPOWERS_HOME}/<module>/skills/<original>/SKILL.md -->` + the original body inlined (Kimi needs the actual content, not a reference)

# Generates platforms/kimi/adapters/ with flat-namespace adapter skills.
# Each adapter inlines (a) the using-gpowers preamble, (b) the source skill body.
set -euo pipefail

: "${GPOWERS_HOME:?GPOWERS_HOME required}"
ADAPTERS_DIR="$GPOWERS_HOME/platforms/kimi/adapters"
mkdir -p "$ADAPTERS_DIR"

# Preamble = using-gpowers body without its frontmatter

---
name: gpowers
description: gpowers entry — four-module model (core / roles / tools / business)
gpowers-source: core/skills/using-gpowers/SKILL.md
---

$PREAMBLE
HEADER

# Every other skill becomes gpowers-<original>

  for s in "$dir"/*/; do
    [ -d "$s" ] || continue
    orig=$(basename "$s")
    [ "$orig" = "using-gpowers" ] && continue
    file="$s/SKILL.md"
    [ -f "$file" ] || continue

    adapter_name="gpowers-$orig"
    adapter_dir="$ADAPTERS_DIR/$adapter_name"
    mkdir -p "$adapter_dir"

    src_frontmatter=$(awk 'BEGIN{fm=0} /^---$/{fm++; if(fm<=2)print; next} fm<2{print}' "$file")
    src_body=$(awk 'BEGIN{fm=0} /^---$/{fm++; next} fm>=2{print}' "$file")
    orig_desc=$(awk -F': ' '/^description:/ {sub(/^description: /, ""); print; exit}' "$file")

    cat > "$adapter_dir/SKILL.md" <<ADAPTER
---
name: $adapter_name
description: $orig_desc (gpowers adapter for Kimi)
gpowers-source: $module/skills/$orig/SKILL.md
gpowers-module: $module
---

<!-- gpowers preamble (auto, four-module model) -->

$PREAMBLE

<!-- SOURCE: \$GPOWERS_HOME/$module/skills/$orig/SKILL.md -->

$src_body
ADAPTER
  done
done

# Flat manifest for Kimi discovery
find "$ADAPTERS_DIR" -mindepth 1 -maxdepth 1 -type d | sort | awk -F/ '{print $NF}' \
  | jq -R . | jq -s '{adapters: .}' \
  > "$GPOWERS_HOME/platforms/kimi/kimi-skills.json"

## Task 7: User-facing `gpowers-platforms` CLI

**Files:**
- Create: `bin/gpowers-platforms`

Wraps the two internal generators with a friendly UX:
- `gpowers platforms list` — what's installed
- `gpowers platforms gen [<platform>]` — generate one or all
- `gpowers platforms verify [<platform>]` — re-validate generated assets

- [ ] **Step 1: Write the CLI**

```bash
cat > bin/gpowers-platforms <<'EOF'
#!/usr/bin/env bash
# Usage:
#   gpowers-platforms list
#   gpowers-platforms gen [<platform>]
#   gpowers-platforms verify [<platform>]
set -euo pipefail

: "${GPOWERS_HOME:?GPOWERS_HOME required}"
SHAPES="$GPOWERS_HOME/platforms/_platform-shapes.json"

all_platforms() { jq -r '.platforms | keys[]' < "$SHAPES"; }

cmd_list() {
  printf '%-12s %-22s %s\n' PLATFORM MANIFEST INSTALL-LINK
  while read -r p; do
    mf=$(jq -r ".platforms.\"$p\".manifest_filename" < "$SHAPES")
    lt=$(jq -r ".platforms.\"$p\".install_link_target" < "$SHAPES")
    printf '%-12s %-22s %s\n' "$p" "$mf" "$lt"
  done < <(all_platforms)
}

cmd_gen() {
  local target="${1:-all}"
  if [ "$target" = "all" ]; then
    while read -r p; do
      if [ "$p" = "kimi" ]; then
        "$GPOWERS_HOME/bin/_gpowers-gen-kimi.sh"
      else
        "$GPOWERS_HOME/bin/_gpowers-gen-platform.sh" "$p"
      fi
    done < <(all_platforms)
  elif [ "$target" = "kimi" ]; then
    "$GPOWERS_HOME/bin/_gpowers-gen-kimi.sh"
  else
    "$GPOWERS_HOME/bin/_gpowers-gen-platform.sh" "$target"
  fi
}

cmd_verify() {
  local target="${1:-all}"
  local rc=0
  verify_one() {
    local p="$1"
    local mf
    mf=$(jq -r ".platforms.\"$p\".manifest_filename" < "$SHAPES")
    local f="$GPOWERS_HOME/platforms/$p/$mf"
    [ -f "$f" ] || { echo "MISSING: $f" >&2; rc=1; return; }
    jq empty < "$f" 2>/dev/null || { echo "INVALID JSON: $f" >&2; rc=1; return; }
    echo "OK: $p"
  }
  if [ "$target" = "all" ]; then
    while read -r p; do verify_one "$p"; done < <(all_platforms)
  else
    verify_one "$target"
  fi
  return $rc
}

case "${1:-}" in
  list)   shift; cmd_list "$@" ;;
  gen)    shift; cmd_gen "$@" ;;
  verify) shift; cmd_verify "$@" ;;
  *) echo "Usage: gpowers-platforms {list|gen|verify} [<platform>]" >&2; exit 2 ;;
esac
EOF
chmod +x bin/gpowers-platforms
```
